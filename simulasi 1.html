Formula Perhitungan

Panduan
1. LTV (Loan to Value):
UP = Taksiran × (LTV % / 100)
2. Rate Jasa Simpan:
JS = Pinjaman × (Rate % / 100) × Pengali Periode
3. STLE (Standar Taksiran Logam Mulia):
STLE = Taksiran ÷ Karatase ÷ Berat
4. Nilai Jual Barang (NJB):
NJB = Gram × STLE × (Karat ÷ 24)
5. Top Up:
• Taksiran - Pelunasan - Admin UP Baru • Taksiran + Admin Baru UP Baru - Pelunasan
6. Top Down:
• Pelunasan - Perkecil = Hasil + Admin UP Baru • UP - Perkecil = Hasil UP Baru + Jasa Simpan + Admin UP Baru
